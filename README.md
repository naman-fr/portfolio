# Naman Gautam Portfolio

A cutting-edge, glassmorphic portfolio website showcasing the work and achievements of Naman Gautam - Systems Engineer, AI Researcher, and Full Stack Developer.

## 🌐 Live Demo

👉 https://portfolio-jet-beta-13.vercel.app/

## Features

- **Glassmorphic Terminal Aesthetic** - Modern, futuristic design with translucent elements
- **Interactive 3D Elements** - React Three Fiber powered 3D kernel visualization
- **Neural Network Background** - Animated particle system with node connections
- **Experience Timeline** - Interactive timeline with scroll-triggered visual changes
- **Bento Grid Projects** - Masonry layout with micro-interactions
- **3D Skills Cloud** - Interactive spherical tag cloud
- **Achievement Showcase** - Animated badges and counters
- **Responsive Design** - Optimized for all screen sizes

## Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animation**: Framer Motion
- **3D Graphics**: React Three Fiber
- **Icons**: Lucide React

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build for Production

```bash
npm run build
npm start
```

## Design Philosophy

This portfolio follows a "Cyber-Physical" design strategy, bridging the gap between low-level systems engineering and high-level AI research. The visual language combines:

- **Obsidian Black** (#0A0A0A) - Deep, professional background
- **Terminal Green** (#00FF41) - Systems-level work
- **Neural Violet** (#7C3AED) - AI/ML projects
- **Warning Amber** (#F59E0B) - Web development
